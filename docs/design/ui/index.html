Реализация макета «gitfs UI.dc.html» (Claude Design, Nocturne). Экраны делят одно состояние: смонтируйте репозиторий в диалоге — он появится в менеджере и меню трея, буква уйдёт из свободных. Это поведенческий контракт для Avalonia-порта.

01 — Mount dialog

Слева выбор, справа результат

Правая колонка — живая: чекбоксы вьюх меняют дерево. Снятая вьюха гаснет и зачёркивается, а не исчезает — выбор остаётся обратимым визуально. Валидации достигаются действиями: выберите занятую букву или сотрите путь.

Mount repository —▫✕
avalonia-lab docs-site terminal

Advanced

Дерево живое: снимите галку — ветка гаснет и зачёркивается, а не исчезает, чтобы выбор оставался обратимым визуально.

Живой диалог: занятые буквы в списке → ошибка с действием; неизвестный путь → not-a-repo; Mount добавляет том в менеджер и трей.
02 — Tray

Состояние читается формой бейджа

Пусто — нет бейджа, число — круг, деградация — треугольник, ошибка — крест: различимо и в монохроме. Состояние вычисляется из реальных монтирований этой страницы — размонтируйте всё, и трей станет Idle.

Mounted · 3
32 px и 16 px — в малом размере число выпадает, остаётся точка
Меню трея
Подменю монтирования

Откройте стрелкой у монтирования слева. Unmount действует по-настоящему — на менеджер, буквы и иконку трея.

03 — Manager

Таблица монтирований и панель деталей

Клик по строке — детали справа: счётчики кэша из status.txt, хвост log.txt. Размонтируйте все тома, чтобы увидеть пустое состояние.

gitfs
04 — Doctor

Вывод считается из состояния страницы

Установите WinFsp в онбординге ниже, включите driver error в трее, размонтируйте том — отчёт пересчитается: колонка статуса 2 знака, имя 22, дальше значение; каждый fail — строка «что сделать» и ссылка.

gitfs doctor
